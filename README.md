# Stefan's Home Assistant Add-ons

> ⚠️ **Work in Progress** — this project is under active early development. Add-on configuration, behavior, and documentation may still change without notice. Use in production at your own risk.

Home Assistant add-on repository for [Nebenkosten-Energierechner](https://github.com/larknafets/nebenkosten-energierechner).

## Installation

Add this repository to your Home Assistant instance:

[![Add repository to your Home Assistant instance][ha-badge]][ha-url]

Or manually: **Settings → Add-ons → Add-on Store → ⋮ → Repositories**, then add:
`https://github.com/larknafets/ha-addons`

[ha-url]: https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Flarknafets%2Fha-addons
