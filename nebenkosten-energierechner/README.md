# Nebenkosten-Energierechner

Monatliche Nebenkostenabrechnung (Strom, Heizung/Warmwasser, Wasser) für ein Zweifamilienhaus mit Wärmepumpe und PV-Anlage.

Dieses Add-on wrappt [nebenkosten-energierechner](https://github.com/larknafets/nebenkosten-energierechner) und bindet es per Ingress ins Home-Assistant-Frontend ein.
